# Security policy

## Reporting a vulnerability

Please do not open a public issue. Report it privately through
[GitHub security advisories](https://github.com/Ravizee-Nation/Film-Platform/security/advisories/new).

Include what you found, how to reproduce it, and the impact you expect. We aim to acknowledge
reports within 3 business days.

## Scope

The platform is in Phase 0 and stores no user data yet. The baseline controls are described in
[docs/security/threat-model.md](docs/security/threat-model.md).
